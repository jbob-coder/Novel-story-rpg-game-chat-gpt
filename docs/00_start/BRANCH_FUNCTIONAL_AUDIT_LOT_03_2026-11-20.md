## Resultado y hallazgos de mayor riesgo

1. **14 de 14 HEAD y PR verificados en GitHub:** los 14 siguen **abiertos y en borrador**, cada uno con su rama base histórica (las dependencias no son lineales desde `main`). Se inspeccionó el archivo nuevo `tools/*.mjs`, su `tests/*.test.mjs` y el JSON de diseño correspondiente; las 14 suites contienen juntas **108 declaraciones `test(...)`**. Son casos enumerados, no 108 tests ejecutados en esta revisión.
2. **14 registros de GitHub Actions por SHA histórico muestran `completed/success`** (run ID en cada fila). Se trata de CI de las ramas en 2026-11; **no** verifica compatibilidad con el HEAD actual de `main`. No se han ejecutado pruebas históricas en esta auditoría, ni se supone que cada PR esté fusionada.
3. **La ciudad vigente ya contiene 15 entradas `world.locations`**, incluyendo cinco lugares de estas propuestas: abarrotes, clínica, punto de entregas, paso cultural y oficinas comerciales. Los cinco se conectan recíprocamente con su distrito principal y registran `access_status: public_confirmed`; `opening_hours: null` no confirma actividad comercial ni apertura presente. Las ramas antiguas #46/#48/#50/#62/#64 utilizan o declaran requisitos de sitios **todavía no admitidos**. El código de #50/#62/#64 comprueba explícitamente ausencia de esos IDs y, dado el checkpoint actual, no puede pasar esa condición. **Actualizar contratos/fixtures sin convertir el boceto en visita del jugador.**
4. **Diseños solapados:** PR #40 y #52 describen el mismo enlace `LOC-COMMERCIAL-DISTRICT ↔ LOC-CROSSWATER-PLAZA` (MB-WEB-007) con **los mismos cinco puntos y cuatro tramos**, aunque módulos, nombres e integración difieren; #42 y #56 definen `LOC-CROSSWATER-PLAZA ↔ LOC-HARBOR-WALK` con **los mismos cinco puntos**, pero #56 emplea el identificador de geometría `MB-WEB-009-DRAFT`. No son dos calles diferentes; resolver una representación canonical de proyecto de mapa antes de importar.
5. **Conflicto real entre borradores #44 y #58:** ambos corresponden a la **misma** conexión directa `LOC-COMMERCIAL-DISTRICT ↔ LOC-HARBOR-WALK`. #44 propone **cinco nodos / cuatro tramos** y coordenadas intermedias `(60,40.7) (64,38.1) (68,36.9)`; #58 propone **seis nodos / cinco tramos** con `(60,39.8) (63.5,37.5) (67.5,36.2) (69.5,36.7)`. Los dos comparten solo los extremos `(58,43)` y `(71,37)`. Su coexistencia como una sola vía dibujada requeriría una decisión de diseño y pruebas de costura; no se permite sumar automáticamente ambos itinerarios.
6. **El grafo base de la novela conserva las 11 conexiones relevantes**, recíprocas, incluyendo el recorrido directo Market–Harbor y el recorrido separado vía Crosswater. En ninguna rama basta una coordenada para otorgar ruta, descubrimiento, apertura, actor, horario, duración, geografía certificada ni contenido narrativo.
