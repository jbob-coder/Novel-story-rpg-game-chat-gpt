## Provisional implementation choices (not owner-approved canon)

- Browser-based, text-first vertical slice using JavaScript without dependencies.
- A small fictional cast of four autonomous NPCs, lightweight society metrics, five placeholder ability categories, and local-only browser saves.
- Seeded awakening probabilities and ecological change frequency are **temporary simulation values**, not fixed world lore.
